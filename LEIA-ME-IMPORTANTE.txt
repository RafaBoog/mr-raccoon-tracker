MR. RACCOON TRACKER — PACOTE PWA FINAL
======================================

Arquivos principais:
- index.html: versão final com layout desktop no celular e zoom por pinça no dossiê.
- manifest.webmanifest: configuração de instalação PWA.
- sw.js: cache offline e pré-cache das 30 provas fotográficas.
- icons/icon-192.png e icons/icon-512.png: ícone provisório do aplicativo.
- assets/: imagens de evidência disponíveis neste pacote.

Como você já tem a pasta assets completa no seu computador/GitHub:
1. Extraia este ZIP por cima da pasta atual do projeto.
2. Quando o Windows perguntar, permita mesclar a pasta assets.
3. NÃO exclua nem substitua imagens antigas que não estejam neste ZIP.
4. Confirme que assets continua contendo os 30 arquivos WebP antes do upload.

ESTRUTURA ESPERADA NO GITHUB
----------------------------
/
  index.html
  manifest.webmanifest
  sw.js
  /assets/   (30 imagens WebP)
  /icons/
    icon-192.png
    icon-512.png

Depois do upload, aguarde o GitHub Pages atualizar e abra o site online.
O service worker usa uma nova versão de cache para forçar a atualização
do aplicativo. A primeira instalação/atualização precisa de internet para
baixar as imagens. O cache do navegador pode ser apagado pelo sistema.
